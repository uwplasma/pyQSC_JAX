# Examples

Each page runs one script from `examples/`. The figures and printed output are produced by
`docs/scripts/fig_examples.py`, which runs every script in a fresh process.

| script | shows |
|---|---|
| {doc}`00_coil_field_finite_beta` | Coil and plasma field on a database stellarator |
| {doc}`01_first_order_qa` | First-order QA |
| {doc}`02_first_order_qh` | First-order QH |
| {doc}`03_second_order_finite_beta` | Second order at finite pressure |
| {doc}`04_target_iota` | Prescribed rotational transform |
| {doc}`05_optimal_B2c` | Exact B2c elimination |
| {doc}`06_optimize_axis_B20` | Nearly constant B20 |
| {doc}`08_boundary_and_coordinates` | Boundary through the ESSOS adapter |
| {doc}`09_total_field_jet` | Total field jet |
| {doc}`10_plasma_external_field_jet` | Plasma and external field jets |
| {doc}`12_autodiff_check` | Implicit derivative check |
| {doc}`13_vmec_export` | VMEC export |
| {doc}`14_vmex_radial_profiles` | VMEX radial profiles |
| {doc}`15_surface_coloring` | Surface colouring by \|B\| and by an error field |
