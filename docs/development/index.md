## Running the tests

```bash
python -m pip install -e '.[dev,plot]'
export JAX_ENABLE_X64=1
python -m pytest                       # everything that needs no optional runtime
python -m pytest -m "not slow"         # skip the example scripts
PYQSC_RUN_VMEX=1 python -m pytest tests/integration        # live VMEX
PYQSC_VMEC_EXECUTABLE=/path/to/xvmec python -m pytest tests/integration   # rerun VMEC
```

At commit `56e1f1c` on an Apple arm64 CPU (Python 3.11, JAX 0.9.2) the suite has 236
tests: 232 pass and 4 are skipped (the live VMEC and VMEX runs), in about 3.5 minutes,
with 99 % line and branch coverage of `src/pyqsc_jax` (the CI gate is 95 %).

## Validation summary

**pyQSC.** Reference arrays were generated with landreman/pyQSC at commit `cd75359`
and are stored with the tests, which never download data. Geometry, $\sigma$, $\iota$,
elongation, field and gradient, the full second-order coefficients, $B_{20}$, Mercier
terms, Hessian, singular radius and the $r^3$ coefficients agree for the vacuum QA
(section 5.1), finite-pressure/current (5.3) and QH (5.4) cases of
{cite:t}`landreman2019highorder` and the first-order QA/QH cases of
{cite:t}`landreman2019numerical`. In a direct rerun at $n_\phi = 121$, scalars agreed to
$8\times10^{-12}$ and the $X_{20}$, $Y_{20}$, $B_{20}$ arrays to $1.1\times10^{-11}$.

**Analytic limits** tested for the plasma field: circular-axis finite part below
$10^{-13}$ and the local-induction logarithm; vanishing core constants for a circular
section; vacuum and pressure-only limits; straight circular and sheared elliptical
channels; the circular finite-conductor curvature limit of the Hessian; spectral and
angular convergence; JIT and radius JVPs. Resolved-volume Biot-Savart references with the
predicted $a^4|\log a|$ error, VMEC2000 radius scans and the benchmarks are in
[plasma-coil-fields](https://github.com/rogeriojorge/plasma-coil-fields/tree/pyqsc-jax-validation/pyqsc_jax_validation).

**VMEC.** A frozen VMEC 9.0 `wout` for the QA example at $r = 0.0025$ m is checked on
every run (checksum, normal termination, force residuals, on-axis $\iota$ within 0.06 %).
With `PYQSC_VMEC_EXECUTABLE` set, the vacuum case and a finite-pressure, zero-current
database case are regenerated and rerun.

## Documentation

```bash
python -m pip install -e '.[docs,plot]'
JAX_ENABLE_X64=1 python docs/scripts/make_all.py     # figures + measurements.json (~3 min)
python -m sphinx -W -b html docs docs/_build/html
```

`make_all.py` runs `measurements.py` (the numbers above and the convergence and overview
figures) and `fig_examples.py` (every example script, its figure and printed output).
Quoted numbers enter the pages as MyST substitutions from
`docs/_static/figures/measurements.json`, whose `_provenance` entry records the commit and
versions that produced them. Rerun the scripts after any change to the numerics.

## Conventions for contributors

* Keep equations readable in the source and give every public function a docstring with
  units and scope.
* `float64` is required and never switched on at import.
* A result that can fail carries a report; failure is data, not an exception, inside
  compiled code.
