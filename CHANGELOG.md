# Changelog

## 0.2.0 (unreleased): the streamlined package

The 0.2 development branch was rebuilt into a smaller package with the same physics.
The full pre-refactor history is on the branch `preserve/pr2-before-refactor-2026-09-27`,
so everything removed below can be recovered.

**Package.** Twelve modules (`spectral`, `geometry`, `solvers`, `models`, `first_order`,
`second_order`, `third_order`, `diagnostics`, `plasma`, `vmec`, `plotting`, `near_axis`)
and an explicit public API in `pyqsc_jax.__all__`. No global side effects on import (no
x64 switch, no Matplotlib defaults, no directories created); VMEX and Matplotlib are
imported lazily.

**Removed from the installed package** (research code or frameworks without validated
use): magnetic shear, target-transform inverse solves, pseudo-arclength continuation,
branch-aware multistart axis search, the named design criteria, the configuration
registry, and the optimizer loops. Examples that need a target-$\iota$ solve or a small
optimizer write it inline in a few lines ({doc}`../user_guide/differentiation`).
Publication figures, benchmarks and the heavy validation scripts moved to
[plasma-coil-fields](https://github.com/rogeriojorge/plasma-coil-fields/tree/pyqsc-jax-validation/pyqsc_jax_validation).

**Solvers.** Implicit derivatives are attached only to converged, regular solves; a failed
solve gives NaN tangents and cotangents. The Newton line search accepts only decreasing
steps and reports `line_search_failed` separately from stagnation. One LU factorization is
shared by the primal and adjoint second-order solves. Condition numbers are Hager-Higham
1-norm estimates ($O(n^2)$); the exact SVD values are computed only on request.

**Performance.** `solve` is compiled with `jax.jit` (scalars traced, resolution and signs
static), so new input values do not recompile. The Mercier terms, field jet and singular
radius are computed on access, or stored with `solve(..., diagnostics=True)`. A full
second-order solution is 2.5 to 3.7 times faster than before the refactor at
$n_\phi = 61$ to 241, and 2 to 8 times faster than pyQSC once compiled.

**Fixes.** Derivatives of `r_singularity` were NaN (the angular-scan seed had a NaN
derivative); they now come from the refined Newton equations and match finite
differences. The `near_axis` adapter coerces inputs to float (no dtype-driven retracing),
stores only the re-laid-out legacy arrays and delegates the rest; it gained `to_vtk`
and lost the legacy tuple API.

**Conventions kept.** `order="r3"` is only the pyQSC flux-constraint correction
({doc}`../theory/third_order`). `to_vmec` writes `MPOL = mpol + 1`
({doc}`../theory/vmec`). Canonical arrays are sample-first; the ESSOS adapter keeps the
historical layouts.

**Documentation.** Rebuilt as this site: theory with the full algorithms, a user guide,
one page per example, and figures and quoted numbers regenerated by `docs/scripts`.
Architecture decision records, refactor status reports, the release checklist and the
migration notes were folded into this changelog.

## 0.2.0.dev: the canonical API (before the streamlining)

The first 0.2 development series replaced the mutable pyQSC-style object with the
immutable JAX core: general Fourier axes with Frenet validity diagnostics; the damped,
reported sigma solve with implicit derivatives through SOLVAX; the complete
finite-pressure/current second order with independent residual checks; the
regular-coordinate total field jet, Mercier terms and singular radius; the $r^3$
flux-constraint correction; exact $B_{2c}$ elimination and $B_{20}$ spectra; the
positive-volume plasma current source, the matched plasma field, gradient and Hessian with
the external $3+5+7$ target; vectorized VMEC export with all four coefficient families and
a frozen VMEC 9.0 `wout` regression; the lazy VMEX bridge; and the ESSOS adapter
`pyqsc_jax.near_axis.near_axis`. It also fixed the legacy `dofs` normal/binormal swap and
the fixed five-step legacy sigma iteration, and made the VMEC export refuse unconverged
boundaries. The item-by-item list is in `CHANGELOG.md` at the repository root.
